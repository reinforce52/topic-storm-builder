# Topic Storm Builder 🌀📚

**关键词知识库一站式构建器 Skill** —— 输入任意关键词，自动完成「STORM 多视角发散 → 深度研究逐类细化 → Obsidian 分层建库（先总后细）」。

适用于：想深入了解某个主题 / 关键词并建立学习型知识库（如"考研控制工程"、"video coding"、"六级英语"——**关键词只是举例，任意主题均可**）。

## 功能特点

- 🔭 **STORM 多视角发散**：从业者 / 研究者 / 怀疑者 / 经济观察者 / 历史观察者 五视角，产出知识大类树（6-10 类）
- 🔍 **深度研究逐类细化**：每大类多角度搜索，产出核心发现 / 定量数据 / 洞察 / 争议 / 信息缺口
- 📁 **Obsidian 先总后细建库**：在 `E:\obsidian\<主题>\` 建立独立 vault，含 `_知识谱系.md`（Mermaid 全库总图）+ 每类 `_总览.md` + 知识点笔记 + `_log.md` 增量日志
- ✅ **强制确认关卡**：发散后先确认大类清单、每细化完一类先展示再继续——避免闷头做完方向不对
- 🔗 **带引用**：每条笔记保留来源 URL，绝不编造

## 工作流

```
意图澄清 → STORM 多视角发散 → 知识大类树 → 用户确认大类清单
→ 逐类深度搜索细化（每类展示结论确认）→ Obsidian 建库 → 写后回读校验
```

## 触发语（豆包侧）

- `用知识库建 <关键词>`
- `topic-storm 建 <关键词>`
- `发散+细化 <关键词>`
- `研究 <关键词> 并建库到 obsidian`

## 目录结构（产出）

```
E:\obsidian\<主题>\
├── _知识谱系.md     # Mermaid mindmap 全库总图
├── _MOC.md          # 总索引 + 学习路线图
├── _log.md          # 增量日志（append-only）
├── 01-<大类A>\       # 每类含 _总览.md + 知识点笔记
├── 02-<大类B>\
└── ...
```
